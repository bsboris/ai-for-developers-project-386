# TimeSpot

Упрощённый сервис онлайн-бронирования, аналог cal.com.

## Концепция

Владелец календаря публикует доступное время для встреч. Гость выбирает свободный слот и записывается на звонок. Без авторизации, личных кабинетов и интеграции с внешними календарями.

## Роли

- **Владелец календаря** — один заранее заданный профиль. Используется в админской части по умолчанию.
- **Гость** — любой пользователь. Бронирует слоты без создания аккаунта.

## Функциональность владельца

- CRUD типов событий (id, название, описание, длительность в минутах)
- Для каждого типа событий настраиваются рабочие часы (по умолчанию будни 9:00–18:00)
- Просмотр страницы предстоящих встреч (список бронирований всех типов событий)
- Блокировка конкретных дат и интервалов (отпуск, выходной)
- Доступ к админ-панели через Basic Auth

## Функциональность гостя

- Просмотр главной страницы со списком типов событий (название, описание, длительность)
- Выбор типа события
- Выбор часового пояса
- Просмотр календаря со свободными слотами на 14 дней вперёд
- Шаг сетки равен длительности события
- Создание бронирования (имя, email, опциональный комментарий)
- Отмена бронирования по ссылке из подтверждения

## Правила занятости

- На одно и то же время нельзя создать две записи, даже для разных типов событий
- Окно бронирования: 14 дней с текущей даты

## Данные гостя при бронировании

- Имя (обязательно)
- Email (обязательно)
- Комментарий (опционально)
